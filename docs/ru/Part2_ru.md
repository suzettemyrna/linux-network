## Part 2. Статическая маршрутизация между двумя машинами

> [English version](../eng/Part2.md)

Для выполнения примеров используются виртуальные машины `ws1` и `ws2`.

> [!NOTE]
> Для организации соединения между виртуальными машинами необходимо создать дополнительную внутреннюю сеть VirtualBox.
>
> 1. Выключить виртуальные машины.
> 2. Открыть меню **Настроить → Сеть**.
> 3. Добавить дополнительный сетевой адаптер с типом подключения **Внутренняя сеть**.
> 4. Указать одинаковое имя сети для обеих машин.
> 5. Запустить виртуальные машины.

![Настройка внутренней сети](../../images/Part2/2.0_1.png)

Проверим список сетевых интерфейсов:

```bash
ip a
```

После добавления второго адаптера в системе появится дополнительный сетевой интерфейс.

**ws1**

![ip a ws1](../../images/Part2/2.0_2_ws1.png)

**ws2**

![ip a ws2](../../images/Part2/2.0_2_ws2.png)

---

Настроим IP-адреса через Netplan.

Файл конфигурации:

```text
/etc/netplan/00-installer-config.yaml
```

Параметры интерфейсов:

| Машина | IP-адрес       | Маска |
| ------ | -------------- | ----- |
| ws1    | 192.168.100.10 | /16   |
| ws2    | 172.24.116.8   | /12   |

**ws1**

![netplan ws1](../../images/Part2/2.0_3_ws1.png)

**ws2**

![netplan ws2](../../images/Part2/2.0_3_ws2.png)

После изменения конфигурации применим настройки:

```bash
sudo netplan apply
```

---

### 2.1. Добавление статического маршрута вручную

Добавим маршруты между машинами с помощью команды:

```bash
sudo ip route add <IP-адрес> dev enp0s8
```

где:

* `route` (`r`) — работа с таблицей маршрутизации;
* `add` — добавление маршрута;
* `dev` — указание сетевого интерфейса;
* `enp0s8` — интерфейс внутренней сети.

На `ws1`:

```bash
sudo ip route add 172.24.116.8 dev enp0s8
ping -c 5 172.24.116.8
```

![ip route add и ping на ws1](../../images/Part2/2.1_1_ws1.png)

На `ws2`:

```bash
sudo ip route add 192.168.100.10 dev enp0s8
ping -c 5 192.168.100.10
```

![ip route add и ping на ws2](../../images/Part2/2.1_1_ws2.png)

Успешный обмен ICMP-пакетами подтверждает наличие маршрута между машинами.

---

### 2.2. Добавление статического маршрута с сохранением

Перезагрузим виртуальные машины:

```bash
sudo reboot
```

Чтобы маршрут сохранялся после перезагрузки, добавим его в конфигурацию Netplan и применим изменения:

```bash
sudo netplan apply
```

Конфигурация `ws1`:

![netplan ws1](../../images/Part2/2.2_1_ws1.png)

Конфигурация `ws2`:

![netplan ws2](../../images/Part2/2.2_1_ws2.png)

В конфигурациях присутствуют два интерфейса:
- `enp0s3` — подключение к внешней сети;
- `enp0s8` — внутренняя сеть между виртуальными машинами.

Проверим соединение повторно.

На `ws1`:

```bash
ping -c 5 172.24.116.8
```

![ping ws1](../../images/Part2/2.2_2_ws1.png)

На `ws2`:

```bash
ping -c 5 192.168.100.10
```

![ping ws2](../../images/Part2/2.2_2_ws2.png)

Соединение сохраняется после перезагрузки, поскольку маршрут настроен через Netplan.
