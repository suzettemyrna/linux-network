## Part 8. Знакомство с SSH Tunnels

> [English version](../eng/Part8.md)

Для выполнения примеров используются виртуальные машины: `r1`, `r2`, `ws11`, `ws21` и `ws22`.

Запустим на `r2` фаервол с правилами из [Части 7](Part7_ru.md).

![firewall](../../images/Part8/8_0.png)

Настроим Apache на `ws22` для прослушивания только локального интерфейса. Для этого в файле `/etc/apache2/ports.conf` заменим строку:

```text
Listen 80
```

на:

```text
Listen localhost:80
```

После изменения конфигурации перезапустим сервис Apache.

![apache2](../../images/Part8/8_1.png)

---

### 8.1. Local TCP Forwarding

Для создания локального SSH-туннеля используется команда:

```bash
ssh -L 8080:localhost:80 10.20.0.20
```

где:

* `-L` — создание локального TCP-туннеля;
* `8080` — локальный порт на текущей машине;
* `localhost:80` — адрес и порт веб-сервера на `ws22`;
* `10.20.0.20` — IP-адрес машины `ws22`.

После установки соединения получаем SSH-сессию на `ws22`.

![ssh](../../images/Part8/8_2.png)

### 8.3. Проверка работы туннелей

Для проверки доступности веб-сервера через созданный туннель выполним команду:

```bash
telnet 127.0.0.1 8080
```

Проверка с `ws11`:

![telnet](../../images/Part8/8_4.png)

Проверка с `ws21`:

![telnet](../../images/Part8/8_5.png)

Успешное подключение к `127.0.0.1:8080` подтверждает, что запрос был передан через SSH-туннель к веб-серверу Apache, работающему на `ws22`.
