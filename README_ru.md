# Linux Networking Lab

> English version: [README.md](README.md)

Практический лабораторный проект по изучению сетевой подсистемы Linux.

В рамках проекта вручную настраивается сеть из нескольких виртуальных машин и последовательно исследуются основные сетевые механизмы Linux: адресация, маршрутизация, DHCP, NAT, firewall, диагностика соединений и SSH-туннелирование.

Все настройки выполняются через консольные инструменты Linux без использования графических интерфейсов.

## Темы проекта

* IP-адресация и подсети
* `ipcalc`
* статическая маршрутизация
* Netplan
* `tcpdump`, `traceroute`
* `iperf3`
* `iptables`
* DHCP
* NAT (SNAT / DNAT)
* SSH tunneling

## Результаты обучения

После выполнения всех лабораторных работ пользователь сможет:

* рассчитывать параметры IPv4-сетей и подсетей;
* настраивать сетевые интерфейсы Linux;
* создавать статические маршруты;
* диагностировать сетевые проблемы;
* измерять пропускную способность соединений;
* настраивать DHCP-сервер;
* конфигурировать NAT и правила фильтрации трафика;
* использовать SSH-туннели для доступа к удалённым сервисам.

## Быстрый старт

Для выполнения лабораторных работ потребуется:

* VirtualBox или аналогичная система виртуализации;
* Ubuntu Server 20.04 или новее;
* права root/sudo;
* не менее пяти виртуальных машин.

Лабораторные работы рекомендуется выполнять последовательно, начиная с [Part 1](docs/ru/Part1_ru.md).
